# 🎮 IndieHaven

Welcome to **IndieHaven**, a community-driven library for discovering and playing small indie games!

Visitors can suggest games through our Discord server. Approved games are manually added to this GitHub repository and automatically appear on the website.

## 📦 Game Submission Requirements

Before adding a game to the repository, please follow these requirements:

1. **Only small games are accepted.** Games must be suitable for a small download.
2. **Maximum file size: 25 MB per file.** No individual file uploaded to the repository should exceed 25 MB.
3. **7-Zip is required.** Install [7-Zip](https://www.7-zip.org/) before preparing games for upload.
4. **Compress games into `.7z` archives.** Use 7-Zip to compress the game files into a `.7z` archive before placing them in the repository.
5. **Check the archive size.** Make sure the resulting `.7z` file is below 25 MB.
6. **Keep game files organized.** Each game must have its own folder inside `games/`.
7. **Add a JSON entry.** Every game must be registered in the root `games.json` file before it can appear on the website.

**Important:** The 25 MB limit applies to every individual file, not the combined size of the entire game folder. Compressing a game does not guarantee it will fit. If the resulting archive is 25 MB or larger, it cannot be uploaded under these rules.

## 🗂️ Adding a Game

1. Create a folder inside `games/` using the game's name.
2. Put its `.7z` archive inside that folder.
3. Add its cover image and screenshots.
4. Add an entry for the game in `games.json`.
5. Commit and push your changes to GitHub.

Once GitHub Pages updates, the game should automatically appear on the website.
